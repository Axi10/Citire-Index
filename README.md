# Index Utilități - Gaz & Curent

Aplicație Android pentru transmiterea automată prin IVR (robot telefonic) a indexului de gaze și curent electric, cu notificări lunare, grafice de consum, estimare a costurilor și rapoarte PDF.

## 📱 Cum descarci și instalezi APK-ul pe telefon

### Metoda 1: Descărcare directă din folderul `release/`
1. Deschide folderul [`release/`](./release) din acest depozit GitHub.
2. Apasă pe fișierul [`index-utilitati.apk`](./release/index-utilitati.apk).
3. Apasă pe butonul **Download** (sau cele 3 puncte -> **Download raw file**).
4. Deschide fișierul descărcat pe telefonul Android și apasă **Instalează**.

---

### Metoda 2: Descărcare din GitHub Actions (Artifacts)
1. În acest depozit GitHub, mergi la tab-ul **Actions**.
2. Selectează ultimul workflow rulat (**Build Android APK**).
3. În partea de jos, la secțiunea **Artifacts**, apasă pe `index-utilitati-apk` pentru a descărca pachetul.
